## 计划大纲

### 6.1 共形映射的概念

- 导数的几何意义：$\arg f'(z_0)$ = 旋转角，$|f'(z_0)|$ = 伸缩率
- **保角性**（$f'(z_0)\ne0$）与伸缩率不变性；共形映射的定义
- 回看 1.5.2 动画：$w=z^2$ 把正交网格变成正交的抛物线网

### 6.2 基本问题

- 已知区域与映射求像；已知两个区域求映射；黎曼映射定理（叙述）

### 6.3 分式线性映射

- $w=\frac{az+b}{cz+d}$ 分解为平移、旋转伸缩、反演 $\frac1z$ 的复合
- **保圆性、保对称性、保交比**（用 1.3.3 的圆的复数方程证明）
- 三点确定一个分式线性映射；上半平面 → 单位圆、单位圆 → 单位圆的标准形式

### 6.4 初等函数构成的映射

- 幂函数 $w=z^n$：角形 → 角形（张角 $\times n$）
- 指数函数 $w=e^z$：带形 → 角形；对数函数反之
- **组合构造**：月牙形、带形、半带形、扇形 → 上半平面 → 单位圆（考试“构造保形映射”题的套路）

## 计划制作的动画

- **保角性**：两条相交曲线及其夹角在 $w=f(z)$ 下的像；$f'(z_0)=0$ 处保角性失效（$z^2$ 在原点角度加倍）
- **$w=1/z$ 的反演**：圆 ↔ 直线、内部 ↔ 外部，在复球面上就是绕水平轴转 180°（承接 1.4 动画）
- **分式线性映射三点定像**：上半平面 → 单位圆盘，实轴 → 单位圆周
- **组合映射流水线**：月牙形 → 角形 → 上半平面 → 单位圆，分步动画演示
